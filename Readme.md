# Employee Card — Mifare Card Manager

โปรแกรมอ่าน/เขียนบัตรพนักงาน **Mifare** ผ่านเครื่องอ่านบัตร Smart Card (PC/SC) พัฒนาด้วย Python (`customtkinter` + `pyscard`) พร้อมระบบจัดการฐานข้อมูลประวัติการเขียนบัตรด้วย SQLite และบันทึก Log รายวันเป็น CSV

---

## สรุปสิ่งที่พัฒนาและอัปเดตล่าสุด (`Write_Card.py` — `v1.3.0`)

### 1. ระบบฐานข้อมูล SQLite (`card_history`)
- จัดเก็บประวัติการเขียนบัตรในตาราง `card_history` (`id`, `created_at`, `uid`, `serial_number`, `card_id`) พร้อม Index ที่คอลัมน์ `card_id`
- สร้างฐานข้อมูลเริ่มต้นให้อัตโนมัติข้างไฟล์โปรแกรม (`.py` หรือ `.exe`):
  - `card_history.db` (ฐานข้อมูลใช้งานจริง)
  - `test.db` (ฐานข้อมูลสำหรับทดสอบ พร้อมข้อมูลตัวอย่าง `69001`–`69005` และซิงค์ไปยังโฟลเดอร์ `dist/` ระหว่างพัฒนา)
- แถบจัดการฐานข้อมูลด้านซ้ายบน:
  - เมนู Dropdown สลับไฟล์ `.db` / `.sqlite` / `.sqlite3` ในโฟลเดอร์โปรแกรม
  - ปุ่ม **เลือกไฟล์ DB...** เพื่อเปิดไฟล์ฐานข้อมูลจากตำแหน่งอื่นในเครื่อง
  - ปุ่ม **+ สร้าง DB** เพื่อสร้างไฟล์ฐานข้อมูลใหม่ทันที
  - ล้างหน้าต่าง Log/สถานะ และโหลดเลขล่าสุดของฐานข้อมูลที่เลือกใหม่ให้อัตโนมัติ

### 2. หน้าจอ UI แบบ 2 ฝั่ง (`1240x740`)
- **ฝั่งซ้าย (ประวัติการเขียนบัตร):**
  - แสดงชื่อฐานข้อมูลที่ใช้งานอยู่ (แยกสีส้มสำหรับ `test.db` และสีเขียวสำหรับฐานข้อมูลอื่น)
  - ช่องค้นหาแบบเรียลไทม์ ค้นหาได้ทั้ง `Card ID`, `UID` และ `Serial Number`
  - ตารางประวัติแยกคอลัมน์ `Card ID` ตัวหนาไว้ด้านขวาสุด พร้อมซิงค์การเลื่อนแนวตั้ง (`Scrollbar` และ `MouseWheel`)
  - จัดเรียง `Card ID` แบบ Natural Sort (`_card_id_sort_key`) รองรับทั้งตัวเลขล้วนและตัวอักษรผสมตัวเลข โดยแสดงเลขมากสุดไว้บนสุด
  - คลิกเลือกแถวในตารางเพื่อนำ `Card ID` นั้นมา `+1` ใส่ในช่องกรอกทันที
- **ฝั่งขวา (อ่าน/เขียนบัตรและสถานะ):**
  - แสดงสถานะการแตะบัตรแบบเรียลไทม์ (`monitor_loop`), `เลขล่าสุดที่เขียน` และ `เลขถัดไป` พร้อมกล่อง Log การทำงาน
- **แถบปุ่มด้านล่าง:**
  - ปุ่ม **ลบรายการที่เลือก** (ลบแถวที่เลือกออกจาก SQLite พร้อมหน้าต่างยืนยัน)
  - ปุ่ม **นำเข้า CSV...**
  - ปุ่ม `-` และ `+` สำหรับเพิ่ม/ลดเลขในช่องกรอก `Card ID` ทีละ 1 (คงจำนวนหลักและเลข `0` นำหน้า เช่น `00099` → `00100`) และช่องกรอกรับเฉพาะตัวเลข `0-9`
  - ปุ่มสถานะการเขียน:
    - สีเขียว **เขียนลงบัตร** เมื่อวางบัตรว่างที่ Authenticate ด้วย Key A (`FF FF FF FF FF FF`) ผ่านและ Block 1 ยังว่างอยู่
    - สีแดง **ยังไม่พร้อมเขียน** เมื่อยังไม่ได้วางบัตร ไม่พบเครื่องอ่าน หรือบัตรมีข้อมูลอยู่แล้ว
- **Footer & About (`Info v1.3.0`):** แสดงข้อมูลผู้พัฒนา (`Bendcemb Software Team` / `bCloud Co., Ltd.`) และหน้าต่าง Pop-up พร้อมลิงก์อีเมลที่คลิกเปิดโปรแกรมเมลได้

### 3. การนำเข้าข้อมูลจาก CSV (`import_csv_to_db`)
- รองรับการอ่านไฟล์ CSV ทั้งเข้ารหัส `utf-8-sig`, `cp874` และ `tis-620`
- ตรวจจับ Header อัตโนมัติ (เช่น `Date`, `UID`, `Serial Number`, `Card ID` รวมถึงชื่อภาษาไทย/อังกฤษอื่น ๆ) และรองรับไฟล์ที่ไม่มี Header (1, 2, 3 หรือ 4+ คอลัมน์)
- คำนวณ `Serial Number` 10 หลักจาก `UID` แบบ Little-Endian อัตโนมัติหากคอลัมน์ Serial Number ว่างอยู่
- ข้ามแถวที่ไม่มี `Card ID` และข้ามรายการที่ `Card ID` ซ้ำกับข้อมูลที่มีอยู่แล้วในฐานข้อมูล
- เรียงข้อมูลจากน้อยไปมากก่อนบันทึกลง SQLite และแสดงสรุปจำนวนที่นำเข้า/ซ้ำ/ข้าม

### 4. การอ่าน/เขียนบัตร Mifare และระบบป้องกันข้อมูลซ้ำ
- อ่าน `UID` ของบัตร และแปลงเป็น `Serial Number` 10 หลักแบบ Little-Endian (`hex_to_decimal_serial`)
- อ่านและเขียนข้อมูลลง **Sector 0 / Block 1** (ความยาวสูงสุด 16 ตัวอักษร, เติม `0x00` ให้ครบ 16 Bytes) ด้วย Key A มาตรฐาน `FF FF FF FF FF FF`
- ตรวจสอบเลข `Card ID` ซ้ำในฐานข้อมูลก่อนเขียน (`find_existing_card_id`) หากซ้ำจะแจ้งเตือนพร้อมวัน-เวลา, `UID` และ `SN` เดิมให้ผู้ใช้ยืนยันก่อนเขียนทับ
- เมื่อเขียนสำเร็จ: บันทึกลง SQLite, บันทึกลงไฟล์ CSV รายวัน (`write_card_YYYY-MM-DD.csv`), รีเซ็ตปุ่มกลับเป็น **ยังไม่พร้อมเขียน**, และรันเลข `Card ID` ถัดไป (`+1`) ให้อัตโนมัติ

## โครงสร้างไฟล์ในโปรเจกต์

| ไฟล์ | คำอธิบาย |
| :--- | :--- |
| `Write_Card.py` | โปรแกรมหลัก **Mifare Card Manager (`v1.3.0`)** แบบ GUI พร้อมระบบ SQLite และนำเข้า CSV |
| `rwcard_win7.py` | โปรแกรม GUI เวอร์ชันก่อนหน้า (`v1.2.0`) ที่รองรับการตั้งค่า DPI Scaling สำหรับ Windows 7 |

| `read_all.py` | สคริปต์อ่านข้อมูลทุก Data Block (Block 0–63) ลงไฟล์ `nfc_data_only_row.csv` (ข้าม Block 0 ที่เป็นข้อมูลโรงงาน และข้าม Sector Trailer: Block 3, 7, 11, ..., 63 พร้อม `strip()` ข้อความและใส่ `-` เมื่อว่าง) |
| `read_sector.py` | สคริปต์ตัวอย่างสำหรับเชื่อมต่อเครื่องอ่าน Load Key A และอ่านข้อมูลจาก Block 4 |
| `write_block1.py` | สคริปต์ตัวอย่างสำหรับ Load Key A และเขียนข้อความตัวอย่างลง Block 1 |
| `requirements.txt` | รายการไลบรารี Python ที่ใช้ในโปรเจกต์ (`customtkinter`, `pyscard`, `pyinstaller` ฯลฯ) |
| `.gitignore` | กำหนดไฟล์ที่ยกเว้นจาก Git (`.venv/`, `build/`, `dist/`, `*.spec`, `*.db`, `*.csv`, `*.log`, `__pycache__/`) |

## การติดตั้งและรันโปรแกรม (Python)

1. สร้างและเปิดใช้งาน Virtual Environment (แนะนำ):
   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   ```
2. ติดตั้ง Dependencies:
   ```powershell
   pip install -r requirements.txt
   ```
3. รันโปรแกรมหลัก:
   ```powershell
   python Write_Card.py
   ```

## การ Build เป็นไฟล์ `.exe` (PyInstaller)

```powershell
python -m PyInstaller --noconfirm --onefile --windowed --collect-all customtkinter Write_Card.py
```

ไฟล์ `.exe` ที่ได้จะอยู่ในโฟลเดอร์ `dist/`
